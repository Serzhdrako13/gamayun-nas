# Встроенные ключи каталога

Открытые ключи ed25519 (`*.pub`, base64 одной строкой — вывод `gamayun-catalog keygen`), которым gamayund доверяет
подпись каталога приложений. Закрытый ключ хранится офлайн у владельца каталога и в репозиторий не попадает.
Дополнительные ключи — `catalog.keys_dir` в конфигурации gamayund.
