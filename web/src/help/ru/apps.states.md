# Состояния приложений

Значок рядом с приложением в списке показывает, что с ним сейчас.

## Что вы видите
| Состояние | Что значит | Что делать |
|---|---|---|
| **работает** | все контейнеры запущены и проходят проверку готовности | — |
| **работает (без проверки готовности)** | запущено, но приложение не умеет сообщать, что готово | если не открывается — смотрите журнал |
| **запускается** | контейнеры стартуют или перезапускаются | подождите |
| **нездорово** | контейнер работает, но не проходит проверку готовности | откройте приложение, **Журнал контейнера** |
| **падает** | приложение упало больше 5 раз за 10 минут и остановлено | исправьте причину по журналу, затем **Запустить** |
| **ошибка** | контейнер завершился с ошибкой или не запустился | журнал, затем **Запустить** или **Изменить** |
| **остановлено** | вы остановили приложение | **Запустить** |
| **ожидание пула** | пул приложений не подключён | см. [недоступны](help:apps.unavailable) |
| **приостановлено** | пул стал только для чтения или занят другой программой | см. [приостановлены](help:apps.unavailable) |
| **удалено (данные сохранены)** | контейнеров нет, данные приложения остались | создать заново с тем же идентификатором или **Удалить** насовсем |

## Как это работает
- **Запустить**, **Остановить**, **Перезапустить** — в строке приложения. **Запустить** снимает
  состояние «падает».
- **Журнал контейнера** в карточке приложения: выберите **Сервис** и число строк (**Строк**: 100–5000),
  нажмите **Обновить**; **Скачать** сохранит журнал файлом. Показывается не больше 1 МиБ.
- **Удалить** — с отметкой **Сохранить данные приложения** (по умолчанию) данные остаются, без неё —
  удаляются безвозвратно вместе с томами приложения.

## Чего не делать
- Не снимайте **Сохранить данные приложения**, пока не забрали нужное: данные удаляются без корзины.

См. также: [Приложения](help:apps).

:::details Для администратора
Детектор «падает»: 5 падений за 10 минут — приложение останавливается. Остановка контейнера
командой `docker restart` падением не считается. Журнал контейнера в интерфейсе ограничен 1 МиБ.
:::
