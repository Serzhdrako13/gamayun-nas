# Пользователи

Раздел **Пользователи и группы** — кто может пользоваться NAS. Одна учётная запись служит для папок
по сети (SMB), веб-раздела **Файлы**, входа по SSH и — для администраторов — входа в этот интерфейс;
пароль у всего общий.

## Что вы видите
- Список пользователей с пометками **администратор**, **отключён**, **пароль не синхронизирован —
  задайте заново**. Колонка **Вход по SSH** — вкл/выкл.
- **Новый пользователь**: **Имя (латиница)**, **Пароль (веб и Samba)**, отметки **Администратор**
  (вход в этот интерфейс) и **Вход по SSH** (по умолчанию — только у администратора).
- У пользователя: **Сменить** пароль, **Отключить** / **Включить**, **Удалить**.
- Группы: стандартные **administrators** и **users**, а также свои — **Новая группа**. **Состав** —
  кто входит в группу.

## Как это работает
- Входить в интерфейс могут члены группы **administrators**; новый пользователь попадает в группу
  **users**.
- Отключённый пользователь не может войти ни в интерфейс, ни в папки по сети; учётка и файлы
  остаются.
- Последнего администратора удалить нельзя; у одного из администраторов всегда остаётся вход по SSH.
- Права на папки выдаются в разделе [Общие папки](help:shares) — пользователям или группам.
- После смены пароля пользователь выходит из всех своих сеансов в интерфейсе и входит заново;
  уже открытые сеансы SSH не прерываются.

## Чего не делать
- Файлы пользователя на пулах при удалении учётки остаются — удалите их сами, если они не нужны.
- Не раздавайте права администратора «на всякий случай»: администратор может удалить пул.

См. также: [Общие папки](help:shares), [Настройки](help:settings).
