# Приложения недоступны, приостановлены или пул занят

Приложения хранят всё на пуле. Если с пулом что-то не так, NAS останавливает Docker, чтобы приложения
не писали «в пустоту» и не испортили данные.

## Что вы видите
- **недоступно** — «Приложения недоступны: пул … не подключён». Пул не смонтирован: например, диски
  не определились после включения.
- **приостановлено** — «Приложения приостановлены: пул … только для чтения». Пул перестал принимать
  запись (ошибка записи или [защита пула](help:storage.pools.readonly)).
- **приостановлено** с текстом «пул … снова доступен на запись — возобновите вручную» — запись
  вернулась, но приложения ждут вашего решения.
- **пул занят** — «Docker остановлен, но пул … занят: процесс <номер> <имя>: …». Docker остановлен, но
  пул держит другая программа: например, открытый в каталоге пула сеанс SSH или консоли, программа
  с открытым файлом пула, процесс контейнера, который не завершился. Пока он держит пул, NAS не может
  отключить или перемонтировать пул. В журнале — одно предупреждение «пул … занят».
- **ошибка** — Docker не запустился; причина — в баннере.

## Что делать
1. **Недоступно**: верните пул (подключите диски, проверьте раздел «Хранилище»). Когда пул снова
   подключён, Docker и приложения запустятся сами.
2. **Приостановлено**: сначала разберитесь с пулом. Когда запись вернулась, нажмите **Возобновить**.
3. **Пул занят**: закройте программу или сеанс из баннера (выйдите из каталога пула в сеансе SSH,
   закройте файл), затем подождите до 15 секунд — состояние сбросится само, и нажмите **Возобновить**.
   Не помогло или процесс не найти — перезагрузите NAS.
4. **Ошибка**: NAS повторяет запуск раз в 5 минут; **Возобновить** — повторить сейчас.

## Чего не делать
- Не включайте Docker вручную по SSH, пока пул недоступен: данные приложений окажутся на системном диске.

См. также: [Приложения](help:apps), [Пул только для чтения](help:storage.pools.readonly).

:::details Для администратора
Состояние пула проверяется раз в 15 секунд, неудачный запуск Docker повторяется раз в 5 минут.
Кто держит пул, можно посмотреть на сервере: `fuser -vm <точка монтирования пула>` или
`lsof +f -- <точка монтирования пула>`.
:::
