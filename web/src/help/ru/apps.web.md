# Веб-адрес приложения

Приложение с веб-интерфейсом можно открыть по своему адресу на NAS, например
`https://jellyfin-<имя-nas>.local/`, без номера порта. Вход — по вашей учётке администратора NAS:
посторонний в сети не попадёт в приложение, даже если у самого приложения пароля нет.

## Что вы видите
- В карточке приложения — **Веб-адрес**: имя (начало адреса перед именем NAS) и порт приложения.
  Подходит только порт приложения «только на этом NAS» (127.0.0.1, TCP).
- **Опубликовать** — адрес появляется сразу. **Снять публикацию** — адрес перестаёт открываться,
  приложение продолжает работать.
- **Корневой сертификат NAS** — файл для установки на компьютер или телефон, чтобы браузер
  доверял адресам приложений.

## Как это работает
1. На NAS работает прокси (служба `gamayun-caddy`, ставится вместе с подсистемой приложений).
   Он принимает запросы на порт 443 и передаёт их приложению.
2. Открывая адрес приложения впервые, вы попадаете на страницу входа NAS. Если вы уже вошли,
   этот шаг проходит сам, за долю секунды. Приложение не получает ваш вход в NAS, только свой.
3. Выход из NAS, смена пароля или отключение учётки закрывают и доступ к приложениям. Пользование
   приложением продлевает вход в NAS.
4. Сертификаты для адресов приложений выпускает сам NAS. Пока корневой сертификат не установлен,
   браузер покажет предупреждение.

## Что делать
- **Установить корневой сертификат.** Скачайте его в карточке приложения и откройте файл:
  в Windows — «Установить сертификат» → «Локальный компьютер» → хранилище «Доверенные корневые
  центры сертификации»; в macOS — «Связка ключей» → «Всегда доверять»; в Android и iOS — через
  настройки безопасности. Сертификат один на NAS, ставится один раз.
- **Адрес не открывается.** Имена `*.local` NAS объявляет по mDNS (Bonjour), как и своё имя. Если устройство не видит
  адрес, пропишите его в DNS роутера или в файле hosts с адресом NAS.
- **«Прокси приложений не установлен или не запущен».** Проверьте службу: `systemctl status gamayun-caddy`.
- **Мобильное приложение (Jellyfin, Immich) не входит.** Такие приложения не умеют страницу входа
  NAS. Для них включите порт «доступно в сети» в настройках приложения.
