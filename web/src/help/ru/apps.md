# Приложения

Приложения — дополнительные программы, которые работают прямо на NAS: медиасервер, фотоальбом,
синхронизация файлов. Каждое живёт в своём **контейнере** — отдельной «коробке» со своими файлами
программы, чтобы приложения не мешали друг другу и самому NAS. Запускает контейнеры Docker.

## Что вы видите
- Переключатель **Приложения** и выбор пула. Пул выбирается один раз: на нём хранятся программы,
  данные приложений и их журналы. Перенести приложения на другой пул в веб-интерфейсе пока нельзя.
- Значок состояния: **работает**, **запуск**, **недоступно**, **приостановлено**, **ошибка**,
  **не установлено**. Что делать в каждом случае — в разделе
  [Приложения недоступны или приостановлены](help:apps.unavailable).
- Список **Установленные приложения** с кнопкой **Добавить приложение** — как добавить, описано в
  разделе [Добавить приложение](help:apps.add).
- Вкладка **Порты** — какие сетевые порты NAS чем заняты ([Порты](help:apps.ports)).
- Вкладка **Каталог** — проверенные приложения с установкой в пару шагов ([Каталог приложений](help:apps.catalog)).

## Как это работает
1. После включения Docker запускается, только когда выбранный пул подключён и доступен на запись.
   Нет пула — Docker не запускается вовсе, чтобы не разложить данные приложений по системному диску.
2. Если пул пропал или стал только для чтения, Docker останавливается вместе со всеми приложениями.
3. Когда Docker снова запущен, приложения, которые должны работать, запускаются сами.

## Чего не делать
- Не запускайте контейнеры вручную по SSH: этот раздел ими не управляет и показывает только их число
  («Контейнеров, запущенных не через этот раздел: …»).

См. также: [Состояния приложений](help:apps.states), [Риски](help:apps.risks).

:::details Для администратора
Подсистема приложений ставится отдельным пакетом `gamayun-nas-apps`. На пуле приложения занимают
скрытую папку `.apps`: `.apps/docker` (образы и контейнеры), `.apps/appdata/<id>` (данные приложения),
`.apps/projects/<id>` (файлы приложения). Выбранный пул записан в `/etc/gamayun-nas/apps.json`.
Журнал службы — `journalctl -u gamayund`.
:::
