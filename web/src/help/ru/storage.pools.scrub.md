# Проверка пула

Проверка данных читает все копии данных на всех дисках пула. Ошибки чтения исправляются с исправной
копии, о найденном приходит уведомление. Это как ревизия на складе: лучше найти испорченную коробку
сейчас, пока есть запасная, чем в день, когда она понадобится.

## Что вы видите
В карточке пула, блок **Проверка данных**: **Последняя завершённая**, **Идёт проверка**, кнопки
**Проверить сейчас** и **Остановить проверку**.

## Как это работает
- Проверка идёт в фоне, пул остаётся доступен; на больших дисках занимает часы.
- По расписанию — раз в 30 дней в 3 часа ночи, пулы по очереди. Расписание меняется в
  [Настройках](help:settings), блок **Проверки по расписанию**. Если сервер был выключен в назначенное
  время, проверка выполнится в ближайший час расписания.
- Проверка доступна только для исправного пула и после окончания начальной синхронизации.

См. также: [Хранилище](help:storage), [Пул неполный (диск выбыл)](help:storage.pools.incomplete).
