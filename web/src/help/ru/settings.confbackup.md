# Резервная копия настроек

Копия настроек — «записная книжка» NAS: пользователи, группы, общие папки и права, настройки
сервера и уведомлений. Если системный диск откажет или систему придётся переустановить, по этой
копии всё восстанавливается за минуты, а не настраивается заново по памяти. Данные с пулов в копию
не входят — только настройки.

## Что вы видите
- **Скачать копию** — сохранить файл копии на компьютер.
- **Сохранить в пулы сейчас** и список **Копии в пулах**.
- **Внешний носитель (USB)** — **Найти носители**, затем **Записать**. Подходит носитель с FAT32,
  exFAT или ext4, не подключённый как пул.
- **Сетевое хранилище (SFTP)** — выгрузка на другой сервер по ключу NAS: добавьте открытый ключ NAS
  пользователю на сервере, **Проверить отпечаток** ключа сервера, отметьте **Отпечаток совпадает**.
  **Выгружать автоматически** — вместе с копиями в пулы; **Выгрузить сейчас** — сразу.
- **Восстановление** — как вернуть настройки из копии.

## Как это работает
- Копия создаётся автоматически при изменении настроек (проверка раз в час) и не реже раза в
  сутки — в каждый пул и на SFTP, если включено; хранятся последние 30 копий.
- Пароли и секреты в копию не входят — при восстановлении они задаются заново.
- На новой установке — кнопка **Восстановить из копии** в мастере первоначальной настройки; копию
  можно взять и с подключённого пула ([Найденные пулы](help:storage.pools.found)).

## Чего не делать
- Не подтверждайте ключ SFTP-сервера, если отпечаток не совпадает с выводом на самом сервере:
  копия может уйти постороннему.

:::details Для администратора
На уже настроенной системе восстановление выполняется с консоли сервера:
```
sudo systemctl stop gamayund
sudo -u gamayun gamayund config plan -file копия.json.gz
sudo -u gamayun gamayund config restore -file копия.json.gz
sudo systemctl start gamayund
```
`config plan` показывает, что будет изменено, ничего не меняя.
:::
