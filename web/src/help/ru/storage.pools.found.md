# Найденные пулы

Пул хранит описание своего состава на самих дисках. После переустановки системы, замены системного диска
или переноса дисков в другой сервер с GamayunNas пул можно подключить обратно — данные на дисках не меняются.

**Как подключить**
1. Подключите все диски пула и откройте «Хранилище» (или шаг «Пул» в мастере настройки).
2. В карточке «Найденные пулы» введите имя пула для подтверждения и нажмите «Подключить».
3. Пул собирается и подключается; тип и состав восстанавливаются с дисков.

**Если найдены не все диски.** Пул с избыточностью (зеркало, RAID5/6, SHR) можно подключить без одного
диска — отметьте «Подключить неполный пул». Он будет в состоянии «Неполный (диск выбыл)», как при выходе
диска из строя. Пулы без избыточности (Basic, JBOD, RAID0) без всех дисков не собираются.

**Настройки после подключения.** На пуле хранятся ежедневные копии настроек (пользователи, папки, права).
В мастере настройки выберите «Восстановить из копии» → «Копия на пуле». Пароли в копию не входят —
задаются заново.

**Когда подключить нельзя.** Пул с тем же именем уже есть; разделы пула заняты; часть слоёв пула
отсутствует. Диски найденного пула нельзя взять под новый пул, пока он не подключён или не очищен.
