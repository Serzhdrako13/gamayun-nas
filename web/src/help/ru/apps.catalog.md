# Каталог приложений

Каталог — список приложений, которые проверил GamayunNas. В отличие от
[своего приложения из compose-файла](help:apps.add), здесь не нужно писать конфигурацию:
достаточно заполнить короткую форму.

## Что значит «Проверено GamayunNas»
- **Подпись.** Каталог подписан ключом проекта. Подделанный архив, изменённый файл или подпись
  неизвестным ключом NAS не примет — каталог просто не загрузится.
- **Закреплённые образы.** Каждый образ указан с контрольной суммой: скачается ровно та версия,
  что проверялась, даже если кто-то подменит её в интернете.
- **Заявленные риски.** Всё, что приложению нужно сверх обычного (доступ к устройствам, особые
  права), записано в каталоге и сверяется с его настройками при установке. Незаявленный риск —
  установка запрещена.
- **Номер каталога только растёт.** Обновление на более старый каталог по сети невозможно; при
  импорте файлом NAS спросит подтверждение.

## Как загрузить или обновить каталог
- **Обновить каталог** — скачать свежий каталог по сети (кнопка есть, если адрес каталога задан).
- **Импорт файлом** — для NAS без интернета: выберите архив `catalog-<версия>.tar.gz`.

## Установка
1. Нажмите **Установить** на карточке приложения.
2. Заполните форму. Пароли с пометкой «Сгенерируется автоматически» NAS придумает сам и сохранит
   в секретах приложения (они не показываются и не попадают в журналы).
3. Выберите общие папки, если приложение их просит, и порты, которые нужно открыть в сеть.
4. **Проверить** — NAS проверит совместимость (версия системы, архитектура, память, диск), подпись
   и риски. Отметьте риски, с которыми согласны ([Риски](help:apps.risks)).
5. **Установить.** Если на любом шаге что-то пойдёт не так или приложение не станет готовым
   вовремя, установка полностью откатится: не останется ни контейнеров, ни учётки, ни пустых данных.

## Обновление и откат
- В карточке приложения: **Проверить обновление** → примечания к версии → **Обновить**.
- Перед обновлением NAS делает **снимок данных** приложения. Если новая версия не запустится или
  не станет готовой — **автоматический откат**: прежняя версия и данные из снимка. В журнале
  появится предупреждение.
- **Откатить на …** — вручную вернуть предыдущую версию. Данные, изменённые после обновления,
  будут потеряны: они вернутся из снимка. Хранятся три последние точки восстановления.
- Если питание пропало посреди обновления, при следующем запуске NAS сам доведёт откат.
- Пометка «миграция данных необратима» значит, что новая версия переделает данные под себя:
  вернуться можно только вместе с данными из снимка.

## Чего не делать
- Не меняйте файлы приложения на пуле вручную: при обновлении они будут перезаписаны.

См. также: [Приложения](help:apps), [Состояния приложений](help:apps.states),
[Доступ к папкам](help:apps.access), [Веб-адрес приложения](help:apps.web).

:::details Для администратора
Каталог — архив `catalog-<версия>.tar.gz` с подписью ed25519; доверенные ключи встроены в систему.
Файлы установленного приложения — `<пул>/.apps/projects/<id>/` (секреты — в файлах с правами 0600),
точки восстановления — `<пул>/.apps/points/<id>/`.
:::
