# Настройки

Настройки — параметры самого сервера: имя и время, вид интерфейса, проверки по расписанию, пороги
температуры, сроки хранения журнала, личные папки, SSH и безопасность входа, сертификат HTTPS.

## Что вы видите
Окно **Настройки** — две вкладки:
- **Сервер** — карточки, описанные ниже.
- **Копия настроек** — резервная копия пользователей, папок и прав:
  [Резервная копия настроек](help:settings.confbackup).

## Имя сервера и время
Смена имени перезапускает службу Samba: открытые сетевые подключения к папкам прервутся. Адрес вида
`имя.local` меняется вместе с именем.

## Вид
**Стиль**: **Вкладки** — раздел во всю рабочую зону; **Рабочий стол** — ярлыки и перетаскиваемые
окна. **Тема** и **Язык** (по умолчанию — язык браузера; тексты, которые приходят с сервера, пока на
русском). Всё это запоминается в этом браузере.

## Проверки по расписанию
| Проверка | По умолчанию | Что делает |
|---|---|---|
| **Проверка данных пулов** | раз в 30 дней | читает все копии данных и исправляет ошибки; пулы по очереди |
| **Короткий SMART-тест дисков** | раз в 7 дней | около 2 минут, работе не мешает |
| **Длинный SMART-тест дисков** | раз в 30 дней | диск сам читает всю поверхность, часы |

Все начинаются в час, заданный полем **Начинать в, час** (по умолчанию — 3 часа ночи по времени
сервера). Если сервер был выключен в назначенное время, пропущенная проверка выполнится один раз в
ближайший час расписания. О найденных проблемах приходят [уведомления](help:notify).
См. также [Проверка пула](help:storage.pools.scrub).

## Температура дисков
Пороги **предупреждение** и **критично** отдельно для HDD и для SSD и NVMe; по умолчанию HDD — 55 и
65 °C, SSD и NVMe — 70 и 80 °C. SMART опрашивается раз в 30 минут; спящий диск не будится.
Перегрев — событие и уведомление не чаще раза в час на диск (рост до «критично» — сразу); возврат
на 3 °C ниже порога — событие «в норме». История температуры — 90 дней. См. [Диски](help:storage.disks).

## Хранение журнала
Сколько дней хранить события каждой важности; те же сроки действуют для уведомлений. Подробно —
[Журнал](help:journal).

## Личные папки
У каждого пользователя личная папка `homes/<имя>` на выбранном пуле: владелец — он сам, остальным
она не видна. По сети она открывается как «homes», в разделе **Файлы** — как **Личная папка**, и
служит домашним каталогом при входе по SSH. При выключении папки на пуле остаются нетронутыми, но
пользователи их больше не видят.

## Служба SSH
SSH — вход в командную строку сервера по сети. После первоначальной настройки SSH выключен. Входят
только пользователи с правом SSH (раздел [Пользователи](help:users)), по паролю учётки NAS; вход
под root запрещён. При выключении открытые сессии остаются — отметка **Разорвать открытые сессии**
прерывает их.

## Защита SSH от перебора паролей
По умолчанию выключена. **Число неудачных попыток** за заданное время — и адрес блокируется на
заданное число минут. При включении адрес вашего компьютера автоматически попадает в исключения,
чтобы вы не заблокировали себя. Блокируется только SSH: вход в этот интерфейс и папки по сети не
затрагиваются. Нужна программа fail2ban на сервере.

## Блокировки входа в веб-интерфейс
После серии неверных паролей вход временно блокируется по адресу и по имени (от 1 секунды до
15 минут, растёт с числом попыток). Браузер, из которого уже был вход, блокировкой имени не
затрагивается. Здесь виден список блокировок и кнопки **Разблокировать** и **Разблокировать все**.
Перезапуск сервера снимает все блокировки.

## Сертификат HTTPS
По умолчанию NAS использует самоподписанный сертификат — браузер предупреждает о нём. Можно
загрузить свой: **Сертификат (PEM)** и **Закрытый ключ (PEM, без пароля)**, затем **Установить**.
Проверяются соответствие ключа, срок, назначение «сервер» и имена. Сертификат действует сразу для
новых соединений; ключ наружу не выдаётся. Отпечаток SHA-256 сверьте с тем, что показывает браузер.
**Вернуть самоподписанный** — отказаться от загруженного.

:::details Для администратора
Файлы конфигурации служб — `/etc/gamayun-nas/gamayund.json` и `/etc/gamayun-nas/gamayun-helper.json`.
Если сертификат задан в конфигурации (`tls.cert_file`), замена из веб-интерфейса отключена.
Журнал служб — `journalctl -u gamayund`.
:::
