# Общие папки

Общая папка — папка на пуле, которую видно по сети: в Windows — как сетевой диск, в macOS и Linux —
как сетевой ресурс (SMB). Как комната в доме: каждому жильцу выдаётся свой ключ — кто-то может
только смотреть, кто-то и переставлять мебель.

## Что вы видите
- Слева — **корневые** общие папки: имя, пул (**пул …**), сводка прав (**запись: … , чтение: …**).
  Кнопки у папки: **Права**, **Снимки**, **Убрать**.
- **Создать папку** — имя, **Описание** и пул. Нет пулов — сначала создайте пул в разделе
  [Хранилище](help:storage).
- Справа — **Вложенные папки** выбранной корневой папки: дерево, где можно создать, переименовать,
  перенести и удалить папку. Файлы и ссылки здесь не показываются; удалить можно только пустую
  папку. Работа с файлами — в разделе [Файлы](help:files).
- Пометка **несовместимо с Windows · переименовать** — имя, которое Windows не покажет или исказит.
- **Применить конфигурацию Samba** — заново записать настройки сетевого доступа, если они сбились.

## Права
- Права задаются на корневой папке и действуют на всё внутри. Уровни: **Нет**, **Чтение**, **Запись**
  (чтение и запись).
- Права выдаются пользователям и группам. Явный запрет (**Нет**) пользователю сильнее разрешения,
  полученного через группу.
- Те же права действуют в веб-разделе **Файлы**.

## Снимки
Снимок — состояние папки на момент времени, как фотография полки: если что-то удалили или испортил
шифровальщик, можно взять из снимка прежнюю версию.
- **Снимки по расписанию**: сколько последних ежечасных, ежедневных, еженедельных и ежемесячных
  снимков хранить — по одному на каждый. Снимок делается с шагом самого частого включённого уровня.
- **Создать снимок сейчас** — ручной снимок; ручные снимки автоматически не удаляются.
- Если на пуле свободно меньше 10 %, снимки по расписанию пропускаются; на пуле только для чтения
  новые снимки не создаются.
- Снимки доступны только для чтения. В Windows прежние версии видны в свойствах файла или папки →
  **Предыдущие версии**.
- **Восстановить** создаёт копию рядом с исходным местом, с временем снимка в имени, — текущие файлы
  не перезаписываются.

## Чего не делать
- **Убрать** снимает папку с сетевого доступа, но каталог и снимки остаются на пуле. Это не
  освобождает место.
- Снимки лежат на том же пуле: при потере пула пропадут и они. Это не замена резервной копии на
  другом устройстве.
