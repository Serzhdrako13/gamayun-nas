# Файлы

Раздел **Файлы** — файловый менеджер прямо в браузере. Он нужен, когда под рукой нет компьютера
с подключённой сетевой папкой: например, загрузить фото с чужого ноутбука или скачать документ
на телефон. Вы видите те же общие папки и с теми же правами, что и по сети (SMB).

## Что вы видите
- **Папка** — выбор общей папки. Доступны только папки, на которые у вас есть права; с пометкой
  **(чтение)** — только для чтения. **Личная папка** появляется, если в **Настройках** включены
  личные папки.
- Строка пути — нажмите на любую часть, чтобы подняться выше. **Обновить** перечитывает папку.
- Таблица: имя, **Размер**, **Изменён**. Отметьте строки флажками (**Выбрать все** — все сразу).
- Кнопки над таблицей:
  - **Загрузить…** — выбрать файлы на компьютере; можно и просто перетащить их в окно;
  - **Новая папка**, **Переименовать** (одна выбранная строка);
  - **Скачать** — каждый выбранный файл скачивается отдельно, папка — архивом zip;
  - **Копировать…**, **Переместить…** — выбрать папку назначения и подпапку (пусто — корень);
  - **Удалить** (или **Удалить (N)** для нескольких).
- Отметка **при совпадении имени — с номером**: если имя занято, новый файл сохранится как
  «имя (2)». Без неё совпадение имени — ошибка, существующий файл не перезаписывается.
- В папке для чтения доступны только просмотр, **Скачать** и **Копировать…** в другую папку,
  где у вас есть запись.

## Как это работает
1. Права — те же, что по сети: с правом чтения можно смотреть и скачивать, с правом записи —
   ещё загружать, создавать, переименовывать, перемещать и удалять. Выдаются права в разделе
   [Общие папки](help:shares).
2. Загрузка идёт по файлу, у каждого — свой ход и кнопка **Отменить**. Итог — «Загружено: N» или
   «Загружено N из M» с причиной для неудавшихся (имя занято, недостаточно места, нет связи).
3. Копирование, перемещение и удаление идут задачей: виден процент и кнопка **Отменить**.
   Отмена останавливает задачу, но то, что уже сделано, остаётся сделанным.
4. Ссылки и специальные файлы показываются, но не открываются из браузера. В очень большой папке
   показываются первые 10 000 записей.

## Чего не делать
- Удаление — **безвозвратно, корзины нет**. Вернуть удалённое можно только из снимка папки, если
  снимки для неё включены (раздел [Общие папки](help:shares)).
- Не загружайте через браузер большие объёмы, если можно подключить папку по сети: так быстрее
  и надёжнее.

См. также: [Общие папки](help:shares), [Пользователи](help:users).
